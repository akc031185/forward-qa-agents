# Fabricated Shop - Regression Test Plan

## TC-01 Guest checkout with a promo code
1. Open https://shop.example.test/catalog
2. Add any product to the cart
3. Apply promo code WELCOME10 at checkout
4. Verify the total is reduced by 10%
